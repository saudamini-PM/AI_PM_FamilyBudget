AI & Data Strategy

Don't train from scratch — leverage what exists

Layer 1: CategorizationMVP → Phase 2

Pre-trained DistilBERT fine-tuned on 68K US bank strings (Hugging Face: us-bank-transaction-categories-v2, 99.9% val accuracy). Rules engine first, ML for edge cases. Review queue for <0.85 confidence.

✓ No GPU required for MVP · Open dataset · Community-licensed

Layer 2: AI Budget Q&AMVP — No fine-tuning needed

GPT-4o / Gemini with structured function calls: get_budget_status, get_transactions, get_spending_summary. Grounded in real DB queries — no raw CSV injection. ~$0.01–0.05/query vs. $0.50+ naive approach.

✓ Function-calling = our IP · Base model handles NL · Cost-controlled

Layer 3: Budget RecommendationsStatistical — no ML

Median / trimmed-mean per category from user's own 3–6 month history + 50/30/20 framing (Elizabeth Warren). No external model needed. Outlier detection (IQR) flags one-time spikes in Phase 2.

✓ Grounded in household data · Explainable · Zero cost

  • Rules engine + pre-trained DistilBERT

✓ What IS sent to Gemini (safe)
  • Aggregated category totals — e.g., "Dining: $234.50"
  • Budget % status — e.g., "75% of $400 limit used"
  • Member count — e.g., "3 members" (no names)
  • Monthly cash flow trends — income vs. expenses by month
  • Public merchant names — Starbucks, Netflix, Amazon
  • Savings goal progress — % saved, months remaining
✗ What is NEVER sent to Gemini
  • Real member names — "Elena" → "Member 1"
  • Household / family name — stripped from system prompt
  • Transaction notes — "Sofia's piano lesson" omitted entirely
  • Personal service providers — "Mrs. Kim" → "[Person]"
  • Gemini API key — browser localStorage only, never transmitted
  • Raw bank file contents — deleted from memory after parse
Layer 1 · System Prompt

Member Anonymization

Real names replaced with generic tokens before every API call. Household name removed entirely.

["Elena","Marco"] → ["Member 1","Member 2"]
Layer 2 · Transaction Tool

Payee Name Scrubbing

Regex detects personal-name titles (Mrs., Dr., Prof.) in payee strings and replaces with [Person].

"Piano - Mrs. Kim" → "Piano - [Person]"
Layer 3 · Notes Field

Notes Omission

Transaction notes are never included in tool responses — they contain free-text member names and personal context.

notes: "Sofia lesson" → (omitted)
